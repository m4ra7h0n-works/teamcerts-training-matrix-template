# TeamCerts training matrix template

A free, practical CSV starter for small teams that need to track employee training and certificates with expiry dates.

## Files

- `training-matrix-template.csv` — blank import-ready template.
- `training-matrix-example.csv` — fictional worked example showing optional training columns.

## How to use

1. Open the CSV in Excel, Google Sheets, LibreOffice, or another spreadsheet tool.
2. Keep the required columns: `name`, `role`, `department`, and `start_date`.
3. Add one optional column for each training or certificate you already track, such as `Forklift Certificate` or `First Aid`.
4. Enter completion dates in those training columns. The examples use `YYYY-MM-DD`.
5. Save or export as UTF-8 CSV before importing it into your own system.

The example contains fictional people only. Do not put health information, government ID numbers, or other sensitive personal data in a training matrix.
